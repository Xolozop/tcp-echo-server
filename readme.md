# Три реализации TCP-эхо сервера

* **src/lvl_1.c — Простой сервер (поток на клиента)** <br>
Thread-per-connection. На каждое новое подключение создаёт отдельный поток, который читает данные и отправляет их обратно.

* **src/lvl_2.c — Быстрый сервер (epoll + пул потоков)** <br>
Один поток через epoll ждёт события на всех сокетах. Когда приходят данные, кидает задачу в очередь, а 4 рабочих потока обрабатывают клиентов.

* **src/lvl_3.c — Очень быстрый сервер (zero-copy)** <br>
То же, что и второй, но данные не копируются в память программы. Использует splice() — данные перекладываются напрямую внутри ядра.

## Быстрый старт

```bash
# Сборка
make

# Запуск (порт 8080)
make run1  # Thread-per-connection 
make run2  # Epoll + Thread Pool
make run3  # Zero-copy (splice)

# Тестирование
echo "Hello" | nc localhost 8080

# Очистка
make clean
